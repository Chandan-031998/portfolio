# Chandan G — Portfolio Website

A responsive developer portfolio built with React, TypeScript and Vite.

## Included

- Responsive single-page portfolio
- Hero / About / Projects / Skills / Experience / Services / Contact
- 7 live production project links
- Project detail modals
- Mobile navigation
- Scroll reveal effects
- Contact form that opens the visitor's email client
- GitHub and LinkedIn links
- SEO title and meta description

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
```

The production-ready files will be generated inside the `dist` folder.

## Deploy

You can deploy the `dist` folder to Netlify, Vercel, Hostinger, cPanel hosting, Cloudflare Pages, or any static hosting provider.

For Netlify/Vercel, connect the GitHub repository and use:

- Build command: `npm run build`
- Output directory: `dist`
